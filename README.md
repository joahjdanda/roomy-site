# Roomy website

Static site for the Roomy iPhone app, served by GitHub Pages: home, privacy policy and support pages.
No build step, no cookies, no analytics; fonts (Inter, Space Grotesk, SIL Open Font License, licences in
`assets/`) and images are served from this repo.

Placeholders to fill in: `SUPPORT_EMAIL` (privacy.html, support.html) and the App Store link (index.html).
